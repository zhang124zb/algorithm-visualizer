## BFS 广度优先搜索

训练范围：通过队列逐层访问节点。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/bfs.html)。

- [ ] **模板** · [洛谷 P1443 · 马的遍历](https://www.luogu.com.cn/problem/P1443)
  - 训练重点：队列分层扩展并记录最短步数。
- [ ] **基础** · [CSES 1193 · Labyrinth](https://cses.fi/problemset/task/1193/)
  - 训练重点：网格最短路径与路径还原。
- [ ] **基础** · [Codeforces 520B · Two Buttons](https://codeforces.com/problemset/problem/520/B)
  - 训练重点：把数值操作视为无权状态图。
- [ ] **进阶** · [CSES 1667 · Message Route](https://cses.fi/problemset/task/1667/)
  - 训练重点：一般无权图最短路径与前驱记录。
- [ ] **进阶** · [CSES 1194 · Monsters](https://cses.fi/problemset/task/1194/)
  - 训练重点：先多源搜索危险到达时间，再搜索可行路线。
- [ ] **困难 · 选做** · [Codeforces 1037D · Valid BFS?](https://codeforces.com/problemset/problem/1037/D)
  - 训练重点：验证访问顺序是否能由BFS产生。

<a id="dfs"></a>

## DFS 深度优先搜索

训练范围：沿一条路径深入再回溯。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/dfs.html)。

- [ ] **模板** · [洛谷 P1605 · 迷宫](https://www.luogu.com.cn/problem/P1605)
  - 训练重点：选择、递归、撤销访问标记。
- [ ] **基础** · [CSES 1192 · Counting Rooms](https://cses.fi/problemset/task/1192/)
  - 训练重点：用DFS标记网格连通块。
- [ ] **基础** · [Codeforces 115A · Party](https://codeforces.com/problemset/problem/115/A)
  - 训练重点：遍历森林并统计层级深度。
- [ ] **进阶** · [CSES 1669 · Round Trip](https://cses.fi/problemset/task/1669/)
  - 训练重点：无向图DFS中区分父边与回边。
- [ ] **进阶** · [Codeforces 580C · Kefa and Park](https://codeforces.com/problemset/problem/580/C)
  - 训练重点：在树上沿路径维护约束状态。
- [ ] **困难 · 选做** · [Codeforces 510B · Fox And Two Dots](https://codeforces.com/problemset/problem/510/B)
  - 训练重点：网格同色区域中的环检测。

## 全排列

训练范围：选择、递归、撤销选择。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/permutations.html)。

- [ ] **模板** · [洛谷 P1706 · 全排列问题](https://www.luogu.com.cn/problem/P1706)
  - 训练重点：按字典序枚举全排列并控制格式。
- [ ] **基础** · [CSES 1622 · Creating Strings](https://cses.fi/problemset/task/1622/)
  - 训练重点：含重复字符的排列去重。
- [ ] **基础** · [Codeforces 124B · Permutations](https://codeforces.com/problemset/problem/124/B)
  - 训练重点：枚举列置换并计算全局目标。
- [ ] **进阶** · [洛谷 P1088 · \[NOIP 2004 普及组\] 火星人](https://www.luogu.com.cn/problem/P1088)
  - 训练重点：理解相邻字典序排列，避免从头枚举所有排列。
- [ ] **进阶** · [洛谷 P1219 · \[USACO1.5\] 八皇后 Checker Challenge](https://www.luogu.com.cn/problem/P1219)
  - 训练重点：在排列搜索中加入列与对角线约束。
- [ ] **困难 · 选做** · [洛谷 P1433 · 吃奶酪](https://www.luogu.com.cn/problem/P1433)
  - 训练重点：排列顺序优化与剪枝，注意全排列的复杂度。

## 迷宫搜索

训练范围：寻找从起点到终点的路径。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/maze.html)。

- [ ] **模板** · [洛谷 P1605 · 迷宫](https://www.luogu.com.cn/problem/P1605)
  - 训练重点：小网格中枚举不重复路径。
- [ ] **基础** · [CSES 1193 · Labyrinth](https://cses.fi/problemset/task/1193/)
  - 训练重点：网格BFS最短路与路线输出。
- [ ] **基础** · [洛谷 P1141 · 01迷宫](https://www.luogu.com.cn/problem/P1141)
  - 训练重点：预处理连通块，复用多次迷宫查询结果。
- [ ] **进阶** · [洛谷 P1162 · 填涂颜色](https://www.luogu.com.cn/problem/P1162)
  - 训练重点：从外部区域搜索，区分内部与外部。
- [ ] **进阶** · [Codeforces 377A · Maze](https://codeforces.com/problemset/problem/377/A)
  - 训练重点：保留连通区域并控制封锁数量。
- [ ] **困难 · 选做** · [CSES 1194 · Monsters](https://cses.fi/problemset/task/1194/)
  - 训练重点：把移动时刻与危险区域的到达时刻结合。

<a id="n-queens"></a>

## N 皇后

训练范围：按行放置皇后并检查冲突。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/n-queens.html)。

选题说明：保留3道直接的N皇后题，另给1道数独作约束搜索迁移选做；不使用无关搜索题凑满6道。

- [ ] **模板** · [洛谷 P1219 · \[USACO1.5\] 八皇后 Checker Challenge](https://www.luogu.com.cn/problem/P1219)
  - 训练重点：N皇后回溯与解的字典序输出。
- [ ] **基础** · [CSES 1624 · Chessboard and Queens](https://cses.fi/problemset/task/1624/)
  - 训练重点：加入不可放置格子的八皇后变式。
- [ ] **进阶** · [洛谷 P1562 · 还是 N 皇后](https://www.luogu.com.cn/problem/P1562)
  - 训练重点：带棋盘限制的N皇后搜索。
- [ ] **困难 · 选做** · [洛谷 P1784 · 数独](https://www.luogu.com.cn/problem/P1784)
  - 训练重点：迁移到数独：维护多类互斥约束。

## 剪枝搜索

训练范围：非负子集和搜索，排除超限或不可能达到的分支。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/pruning.html)。

- [ ] **模板** · [洛谷 P1036 · \[NOIP 2002 普及组\] 选数](https://www.luogu.com.cn/problem/P1036)
  - 训练重点：组合枚举中控制选择数量与剩余容量。
- [ ] **基础** · [CSES 1623 · Apple Division](https://cses.fi/problemset/task/1623/)
  - 训练重点：按两组和组织子集搜索。
- [ ] **基础** · [洛谷 P1025 · \[NOIP 2001 提高组\] 数的划分](https://www.luogu.com.cn/problem/P1025)
  - 训练重点：固定非降顺序，避免重复划分。
- [ ] **进阶** · [洛谷 P1433 · 吃奶酪](https://www.luogu.com.cn/problem/P1433)
  - 训练重点：使用当前代价与最优答案进行界限剪枝。
- [ ] **进阶** · [洛谷 P1784 · 数独](https://www.luogu.com.cn/problem/P1784)
  - 训练重点：优先搜索候选较少的位置并及时判冲突。
- [ ] **困难 · 选做** · [洛谷 P1120 · \[CERC 1995\] 小木棍](https://www.luogu.com.cn/problem/P1120)
  - 训练重点：识别等价分支、长度界限与失败状态。

<a id="memo-search"></a>

## 记忆化搜索

训练范围：缓存递归子问题，避免重复计算。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/algorithms/traversal/memo-search.html)。

选题说明：检查是否为无环依赖，并考虑递归深度；缓存只消除重复子问题，不自动解决深递归栈溢出。

- [ ] **模板** · [洛谷 P1464 · \[PacNW 1999\] Function](https://www.luogu.com.cn/problem/P1464)
  - 训练重点：递归函数缓存，先检查边界再访问表。
- [ ] **基础** · [洛谷 P1028 · \[NOIP 2001 普及组\] 数的计算](https://www.luogu.com.cn/problem/P1028)
  - 训练重点：对子问题整数建立缓存。
- [ ] **基础** · [洛谷 P1216 · \[IOI 1994 / USACO1.5\] 数字三角形 Number Triangles](https://www.luogu.com.cn/problem/P1216)
  - 训练重点：自顶向下缓存三角形路径的最优值。
- [ ] **进阶** · [洛谷 P1434 · \[SHOI2002\] 滑雪](https://www.luogu.com.cn/problem/P1434)
  - 训练重点：按严格高度关系构成DAG并缓存最优路径。
- [ ] **进阶** · [洛谷 P4017 · 最大食物链计数](https://www.luogu.com.cn/problem/P4017)
  - 训练重点：缓存有向无环图中的路径计数。
- [ ] **困难 · 选做** · [洛谷 P1040 · \[NOIP 2003 提高组\] 加分二叉树](https://www.luogu.com.cn/problem/P1040)
  - 训练重点：缓存区间最优值，并记录构造信息。
