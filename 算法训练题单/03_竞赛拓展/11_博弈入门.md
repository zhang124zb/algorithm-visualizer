## 胜负态递推

训练范围：博弈入门。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/competition/games/win-lose.html)。

- [ ] **模板** · [CSES 1729 · Stick Game](https://cses.fi/problemset/task/1729/)
  - 训练重点：从允许操作集合递推胜态和败态。
- [ ] **基础** · [CSES 1730 · Nim Game I](https://cses.fi/problemset/task/1730/)
  - 训练重点：观察多堆取石规则下的胜负特征。
- [ ] **基础** · [CSES 1098 · Nim Game II](https://cses.fi/problemset/task/1098/)
  - 训练重点：对照每次最多取若干个的规则变化。
- [ ] **进阶** · [Codeforces 1382B · Sequential Nim](https://codeforces.com/problemset/problem/1382/B)
  - 训练重点：限制操作顺序后重新分析状态。
- [ ] **进阶** · [Codeforces 1396B · Stoned Game](https://codeforces.com/problemset/problem/1396/B)
  - 训练重点：选择不同石堆时的不变量与反制。
- [ ] **困难 · 选做** · [Codeforces 1194D · 1-2-K Game](https://codeforces.com/problemset/problem/1194/D)
  - 训练重点：参数化操作集合下寻找稳定胜负规律。

<a id="nim"></a>

## Nim 游戏

训练范围：博弈入门。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/competition/games/nim.html)。

选题说明：后半部分是 Nim 规则变式对照，不意味着标准异或结论对任何取石游戏都成立。

- [ ] **模板** · [洛谷 P2197 · 〖模板〗Nim 游戏](https://www.luogu.com.cn/problem/P2197)
  - 训练重点：标准 Nim 的多堆状态与异或。
- [ ] **基础** · [CSES 1730 · Nim Game I](https://cses.fi/problemset/task/1730/)
  - 训练重点：对标准规则进行多组数据判断。
- [ ] **基础** · [CSES 1098 · Nim Game II](https://cses.fi/problemset/task/1098/)
  - 训练重点：先改变单堆允许操作，再分析多堆组合。
- [ ] **进阶** · [CSES 1099 · Stair Game](https://cses.fi/problemset/task/1099/)
  - 训练重点：阶梯移动规则与有效石堆信息。
- [ ] **进阶** · [Codeforces 1382B · Sequential Nim](https://codeforces.com/problemset/problem/1382/B)
  - 训练重点：顺序限制下不能直接套用标准 Nim。
- [ ] **困难 · 选做** · [Codeforces 1396B · Stoned Game](https://codeforces.com/problemset/problem/1396/B)
  - 训练重点：最大堆与其余堆的关系分析。
  - 提醒：变式规则和标准 Nim 不同，先重新审查合法操作。
