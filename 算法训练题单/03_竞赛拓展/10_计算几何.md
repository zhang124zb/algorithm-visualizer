## 叉积与方向

训练范围：计算几何。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/competition/geometry/cross-product.html)。

- [ ] **模板** · [CSES 2189 · Point Location Test](https://cses.fi/problemset/task/2189/)
  - 训练重点：整数叉积的正负与共线判定。
- [ ] **基础** · [CSES 2191 · Polygon Area](https://cses.fi/problemset/task/2191/)
  - 训练重点：用有向边叉积累计面积。
- [ ] **基础** · [CSES 2190 · Line Segment Intersection](https://cses.fi/problemset/task/2190/)
  - 训练重点：以转向判定支持线段相交。
- [ ] **进阶** · [洛谷 P1355 · 神秘大三角](https://www.luogu.com.cn/problem/P1355)
  - 训练重点：三角形内外与边界的位置关系。
- [ ] **进阶** · [CSES 2192 · Point in Polygon](https://cses.fi/problemset/task/2192/)
  - 训练重点：在多边形判定中处理边、顶点与射线。
- [ ] **困难 · 选做** · [CSES 2193 · Polygon Lattice Points](https://cses.fi/problemset/task/2193/)
  - 训练重点：面积与格点边界计数相结合。
  - 提醒：困难延伸，需要格点计数与 Pick 定理。

<a id="segment-intersection"></a>

## 线段相交

训练范围：计算几何。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/competition/geometry/segment-intersection.html)。

- [ ] **模板** · [CSES 2190 · Line Segment Intersection](https://cses.fi/problemset/task/2190/)
  - 训练重点：跨立、共线与包围盒条件。
- [ ] **基础** · [CSES 2189 · Point Location Test](https://cses.fi/problemset/task/2189/)
  - 训练重点：先校验方向判定的整数实现。
  - 提醒：叉积前置复习题，不是完整线段相交题。
- [ ] **基础** · [洛谷 P1355 · 神秘大三角](https://www.luogu.com.cn/problem/P1355)
  - 训练重点：练习点落边界和端点的分类。
  - 提醒：点位置前置题，先稳固边界判断。
- [ ] **进阶** · [Codeforces 593B · Anton and Lines](https://codeforces.com/problemset/problem/593/B)
  - 训练重点：把区间两端的直线相对次序与相交联系起来。
- [ ] **进阶** · [Codeforces 27D · Ring Road 2](https://codeforces.com/problemset/problem/27/D)
  - 训练重点：由弦相交关系建立冲突图。
  - 提醒：综合题还需要二分图染色；不要在学习线段模板时强行完成。
- [ ] **困难 · 选做** · [CSES 2192 · Point in Polygon](https://cses.fi/problemset/task/2192/)
  - 训练重点：多次组合相交判定完成多边形位置查询。

<a id="convex-hull"></a>

## 凸包

训练范围：计算几何。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/competition/geometry/convex-hull.html)。

- [ ] **模板** · [洛谷 P2742 · 〖模板〗二维凸包 / \[USACO5.1\] 圈奶牛Fencing the Cows](https://www.luogu.com.cn/problem/P2742)
  - 训练重点：排序、转向与上下凸壳的构造。
- [ ] **基础** · [CSES 2195 · Convex Hull](https://cses.fi/problemset/task/2195/)
  - 训练重点：输出凸包顶点并明确共线点规则。
- [ ] **基础** · [洛谷 P1355 · 神秘大三角](https://www.luogu.com.cn/problem/P1355)
  - 训练重点：方向判定与凸多边形点位置的前置复习。
  - 提醒：这是三角形位置题，不是凸包构造题。
- [ ] **进阶** · [Codeforces 166B · Polygons](https://codeforces.com/problemset/problem/166/B)
  - 训练重点：利用凸多边形顺序处理包含关系。
- [ ] **进阶** · [洛谷 P3829 · \[SHOI2012\] 信用卡凸包](https://www.luogu.com.cn/problem/P3829)
  - 训练重点：将带圆角图形的边界组织为凸包问题。
- [ ] **困难 · 选做** · [洛谷 P1452 · \[USACO03FALL\] Beauty Contest G](https://www.luogu.com.cn/problem/P1452)
  - 训练重点：凸包上的最远点对。
  - 提醒：困难延伸，需要另外学习旋转卡壳。
