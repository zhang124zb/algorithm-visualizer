## 树状数组

训练范围：lowbit、前缀聚合、差分、离散化与顺序统计。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/structures/advanced/fenwick.html)。

- [ ] **模板** · [洛谷 P3374 · 〖模板〗树状数组 1](https://www.luogu.com.cn/problem/P3374)
  - 训练重点：完成单点加和区间求和，注意一基下标。
- [ ] **基础** · [CSES 1648 · Dynamic Range Sum Queries](https://cses.fi/problemset/task/1648/)
  - 训练重点：将单点赋值转为与旧值的差，再更新树状数组。
- [ ] **基础** · [CSES 1651 · Range Update Queries](https://cses.fi/problemset/task/1651/)
  - 训练重点：在差分数组上标记区间两端，单点值用前缀和取得。
- [ ] **进阶** · [CSES 1749 · List Removals](https://cses.fi/problemset/task/1749/)
  - 训练重点：用树状数组维护存活个数，二进制提升寻找第 k 个。
  - 提醒：需要顺序统计扩展，不能线性扫描寻找每个删除位置。
- [ ] **进阶** · [CSES 1144 · Salary Queries](https://cses.fi/problemset/task/1144/)
  - 训练重点：离线收集薪资进行离散化，再维护修改后的区间人数。
- [ ] **困难 · 选做** · [Codeforces 459D · Pashmak and Parmida's problem](https://codeforces.com/problemset/problem/459/D)
  - 训练重点：从左右累计出现次数，用树状数组统计频次之间的大小关系。
  - 提醒：提高题：先明确两侧频次定义，再选择扫描顺序。

<a id="segment-tree"></a>

## 线段树

训练范围：节点聚合、单点更新、区间查询与懒标记。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/structures/advanced/segment-tree.html)。

- [ ] **模板** · [CSES 1648 · Dynamic Range Sum Queries](https://cses.fi/problemset/task/1648/)
  - 训练重点：用区间和聚合实现建树、单点赋值和区间查询。
- [ ] **基础** · [CSES 1649 · Dynamic Range Minimum Queries](https://cses.fi/problemset/task/1649/)
  - 训练重点：将合并函数从求和改成取最小值。
- [ ] **基础** · [Codeforces 339D · Xenia and Bit Operations](https://codeforces.com/problemset/problem/339/D)
  - 训练重点：按树层选择或运算与异或运算，维护单点修改。
- [ ] **进阶** · [CSES 1143 · Hotel Queries](https://cses.fi/problemset/task/1143/)
  - 训练重点：在区间最大值上向下寻找第一个可容纳的酒店。
- [ ] **进阶** · [洛谷 P3372 · 〖模板〗线段树 1](https://www.luogu.com.cn/problem/P3372)
  - 训练重点：增加区间加懒标记，处理标记下传及区间长度。
  - 提醒：提高扩展：演示只覆盖单点修改，此题需要新增懒标记。
- [ ] **困难 · 选做** · [CSES 1190 · Subarray Sum Queries](https://cses.fi/problemset/task/1190/)
  - 训练重点：为节点维护总和、最优前缀、最优后缀与最大子段和。
  - 提醒：提高题：需要先理解最大子段和及四种状态的合并。
