基础分类整理日期：2026-10-25。来源仅使用 Codeforces、洛谷、CSES；每道题都附官方题目链接。

基础分类覆盖网站现有 **120 个演示知识点、16 个 STL 细分知识点，以及 1 个代码实验室综合练习入口**，共 **137 个知识点/入口、33 份分类题单、809 条练习安排、513 道去重后的题目**。同一题可以服务多个知识点，重复出现表示指定不同实现或分析角度，去重数量不等于安排数量。

## 使用方式

1. 每节先做“模板”，再做基础与进阶；困难题为选做。默认约 6 题，少数窄主题宁缺毋滥，原因写在对应小节。
2. “模板”是本知识点的起手练习；只有官方题名明确标注模板时才代表平台模板题。普通题通常允许多种算法，题单给的是训练建议。
3. 建议先自己建模并写出复杂度，再去平台提交；复练同题时可指定手写结构或改用 STL。不要因换了模块就重复计为新题。
4. 本题单不附题解或答案。链接、题号与题名已对照官方来源核对；尚未为全部题目编写和提交标程。
5. 浏览器代码实验室仅支持教学子集且有规模上限；OJ 标准规模与任意官方题解请使用平台或完整 C++17 本机环境。预留但尚未开发的高级主题不混入现有模块必刷范围。

## 建议顺序

数组与链表 → 基础方法与 STL → 基础技巧、查找、排序 → 栈队列与搜索 → 树、图、动态规划 → 区间结构与数学 → 竞赛拓展。前序、中序、后序等顺序题可以共用同一道建树题复练；STL 题单侧重接口使用，结构原理题单侧重实现与复杂度。
