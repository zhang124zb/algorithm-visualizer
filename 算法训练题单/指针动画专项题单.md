## 怎样配合动画练习

1. 先看对应的本地演示，再用 5～8 个元素手动记录每一步指针指向哪里、维护什么条件，以及为什么可以排除某一段。
2. `left/right/mid` 等是建议观察的变量名，不是题目强制的写法。两根箭头指向同一位置，并不代表两个变量已经合成一个变量。
3. 区分真实元素、`-1` 与尾后位置 `n`；尾后位置可以比较，不能直接读取。
4. 答案二分的 `lo/hi/mid` 往往是高度或时间等候选值，不是数组下标。可手绘候选数轴或用变量观察记录，不要把候选数值直接指到数组格子。
5. 代码实验室仅根据常见变量名辅助推断下标，不能精确分析任意程序的变量用途。浏览器模式有语法和数据规模限制，标准规模请到 OJ 或完整本机 C++ 环境运行。

本地演示链接指向项目现有 HTML 文件；在线博客需在本轮前端改动发布后才会显示新箭头。题单只给训练观察点，不提供完整题解。

## 相向双指针

配套本地演示：[双指针](../dist/algorithms/techniques/two-pointers.html)。

- [ ] **模板** · **原题复练** · [CSES 1640 · Sum of Two Values](https://cses.fi/problemset/task/1640/)
  - 训练重点：在有序候选中寻找不同位置的两数之和。
  - 关注指针：`left / right`。
  - 移动观察：每次移动前先说明哪一端会改变当前和的方向，并保持 left &lt; right。
  - 提醒：旧题单已收录，本节按箭头移动规则复练。 排序时保留原始下标，平台要求返回原位置。
- [ ] **基础** · **新增补充** · [Codeforces 1462A · Favorite Sequence](https://codeforces.com/problemset/problem/1462/A)
  - 训练重点：从两端交替取数，还原原始序列。
  - 关注指针：`left / right`。
  - 移动观察：每取一个端点只移动对应一侧；特别检查 left == right 时中间元素只处理一次。
  - 提醒：本次新增补充；已核对官方题面。
- [ ] **基础** · **新增补充** · [Codeforces 381A · Sereja and Dima](https://codeforces.com/problemset/problem/381/A)
  - 训练重点：模拟玩家从左右端取牌，区分当前剩余区间与双方得分。
  - 关注指针：`left / right`。
  - 移动观察：每轮只移动实际取牌的一端，观察指针相遇前后的剩余元素数。
  - 提醒：本次新增补充；已核对官方题面。
- [ ] **进阶** · **新增补充** · [Codeforces 1006C · Three Parts of the Array](https://codeforces.com/problemset/problem/1006/C)
  - 训练重点：维护左右两段累计和，寻找等和且不重叠的分段。
  - 关注指针：`left / right`。
  - 移动观察：将两端累计和与尚未分配的 [left,right] 分开观察，移动后检查两段不得重叠。
  - 提醒：本次新增补充；已核对官方题面。 题目数组元素为正；累计和应使用足够宽的整数。
- [ ] **进阶** · **新增补充** · [Codeforces 1399C · Boats Competition](https://codeforces.com/problemset/problem/1399/C)
  - 训练重点：固定配对总重量后，统计互不复用的二人组。
  - 关注指针：`left / right`。
  - 移动观察：观察两端比较如何排除候选；更换目标总重量时，要把两个指针与本轮使用状态重新初始化。
  - 提醒：本次新增补充；已核对官方题面。 存在多个候选总重量，不能只做一次固定目标的两数之和。
- [ ] **困难 · 选做** · **新增补充** · [Codeforces 1157C2 · Increasing Subsequence (hard version)](https://codeforces.com/problemset/problem/1157/C2)
  - 训练重点：从两端选择元素构造尽量长的严格递增序列。
  - 关注指针：`left / right`。
  - 移动观察：两端数值相等时暂停普通的单步选择，观察从两侧继续拿取的可行长度差异。
  - 提醒：本次新增补充；已核对官方题面。 困难选做；输入允许重复值，不能沿用 easy version 的互异假设。

  - 关注指针：`left / right`。
  - 移动观察：right 加入新元素后，观察窗口和超出目标时 left 如何恢复约束。
  - 提醒：旧题单已收录，本节按箭头移动规则复练。 正整数条件保证窗口和的单调变化；不要直接套到含负数的 Subarray Sums II。

  - 关注指针：`left / right`。
  - 移动观察：right 向右加入新书，left 只为恢复时间约束而右移；两端都不回退。
  - 提醒：旧题单已收录，本节按箭头移动规则复练。

  - 提醒：旧题单已收录，本节按箭头移动规则复练。
- [ ] **进阶** · **新增补充** · [Codeforces 676C · Vasya and String](https://codeforces.com/problemset/problem/676/C)

  - 关注指针：`left / right`。
  - 移动观察：分别观察把窗口统一成 a 或 b 时，修改预算超限如何推动 left。
  - 提醒：本次新增补充；已核对官方题面。
- [ ] **进阶** · **新增补充** · [CSES 2428 · Distinct Values Subarrays II](https://cses.fi/problemset/task/2428/)

  - 关注指针：`left / right`。
  - 移动观察：指针按月份移动而长度约束按天计算，重点观察左边月份只取部分天时的边界。
  - 提醒：本次新增补充；已核对官方题面。 困难选做；另需环形展开、等差数列求和与宽整数，不能按全部天数逐个展开。

## 二分与边界指针：从数组位置到答案值域

配套本地演示：[二分查找](../dist/algorithms/search/binary-search.html) · [左边界](../dist/algorithms/search/lower-bound.html) · [右边界](../dist/algorithms/search/upper-bound.html) · [二分答案](../dist/extensions/competition/selection/binary-answer.html)。

- [ ] **模板** · **原题复练** · [洛谷 P2249 · 〖深基13.例1〗查找](https://www.luogu.com.cn/problem/P2249)
  - 训练重点：练习首次出现位置，区分找到了相等元素与找到了插入边界。
  - 关注指针：`left / right / mid`。
  - 移动观察：采用左闭右开区间时，观察 right 的尾后位置；用重复元素、目标小于最小值及大于最大值检验每次边界收缩。
  - 提醒：旧题单已有，可直接复练；若位置落在 n，不能再读取数组元素。
- [ ] **基础** · **原题复练** · [Codeforces 706B · Interesting drink](https://codeforces.com/problemset/problem/706/B)
  - 训练重点：把不超过预算的元素数量转成第一个严格大于预算的位置，比较 upper_bound 与 lower_bound 的差别。
  - 关注指针：`left / right / mid`。
  - 移动观察：加入多个相同价格，观察等于预算的值应该留在哪一侧，再检查边界停在 0 或 n 时的含义。
  - 提醒：旧题单已有；先排序，边界位置表示数量，不一定对应可读取的元素。
- [ ] **基础** · **新增补充** · [Codeforces 1676E · Eating Queries](https://codeforces.com/problemset/problem/1676/E)
  - 训练重点：在整理后的前缀和上寻找首次达到目标的位置，区分输入顺序、排序后顺序与候选人数。
  - 关注指针：`left / right / mid`。
  - 移动观察：让箭头跟随前缀和的候选位置，分别观察恰好达到目标及总量仍不足时，收缩区间与尾后结果有何不同。
  - 提醒：相对旧题单新增；需先学排序与前缀和，每次询问相互独立。
- [ ] **进阶** · **新增补充** · [Codeforces 1613C · Poisoned Dagger](https://codeforces.com/problemset/problem/1613/C)
  - 训练重点：把二分对象从数组下标改为候选持续时间，观察最小可行答案的单调分界。
  - 关注指针：`lo / hi / mid`。
  - 移动观察：先为两端写清可行或不可行含义，再逐轮记录 mid 的判定结果，检查被舍弃的区间是否始终不含最小可行值。
  - 提醒：相对旧题单新增；lo/hi/mid 是答案值，不是攻击时间数组的下标。完整数据需要 64 位整数，判定累计量也应防溢出。
- [ ] **进阶** · **新增补充** · [Codeforces 1873E · Building an Aquarium](https://codeforces.com/problemset/problem/1873/E)
  - 训练重点：观察最大可行高度，与上一题最小可行时间的收缩方向进行对照。
  - 关注指针：`lo / hi / mid`。
  - 移动观察：在候选高度数轴上标出可行区与超预算区，尤其检查只剩两个候选值时 mid 和边界是否仍会移动。
  - 提醒：相对旧题单新增；分层按本专项训练顺序，非平台难度等级。候选值是水位高度，消耗总量应使用足够宽的整数类型。
- [ ] **困难 · 选做** · **新增补充** · [Codeforces 448D · Multiplication Table](https://codeforces.com/problemset/problem/448/D)
  - 训练重点：在未显式存储的有序多重数据上二分答案值域，用单调计数定位第 k 项。
  - 关注指针：`lo / hi / mid`。
  - 移动观察：把箭头画在候选数值线上，观察重复乘积造成的计数跳变，并检验收敛点两侧分别属于哪个判定区域。
  - 提醒：相对旧题单新增，选做；按题面非降序排列的定义理解第 k 项，重复值占多个位置。不能建立完整乘法表，乘积范围与计数需使用 64 位整数。

## 栈队列与节点移动

配套本地演示：[栈](../dist/structures/stack-queue/stack.html) · [队列](../dist/structures/stack-queue/queue.html) · [循环链表](../dist/structures/linear/circular-linked-list.html) · [双向链表](../dist/structures/linear/doubly-linked-list.html)。

- [ ] **模板** · **原题复练** · [洛谷 P1996 · 约瑟夫问题](https://www.luogu.com.cn/problem/P1996)
  - 训练重点：以循环链表或循环队列复练报数与移除过程，区分节点身份和显示位置。
  - 关注指针：`current/prev/next`。
  - 移动观察：比较节点移除前后的 prev/next 连线，以及 current 随报数和删除发生的位置变化。
  - 提醒：原题单已收录；本次指定观察节点连线复练，平台不强制使用链表。
- [ ] **基础** · **新增补充** · [Codeforces 1234B1 · Social Network (easy version)](https://codeforces.com/problemset/problem/1234/B1)
  - 训练重点：处理容量有限的会话列表，区分新会话、重复消息与满容量时的移除。
  - 关注指针：`front/back`。
  - 移动观察：对照新会话加入、旧会话离开和重复消息三种情况，观察两端位置是否改变。
  - 提醒：本次新增；标准输入输出。先约定哪一端保存最近会话，最终显示顺序必须与题面一致。
- [ ] **基础** · **新增补充** · [Codeforces 1428C · ABBB](https://codeforces.com/problemset/problem/1428/C)
  - 训练重点：练习相邻字符消除后的已处理状态与栈顶变化。
  - 关注指针：`i/top`。
  - 移动观察：在一次合法相邻消除发生前后，比较输入游标 i 和临时结构的 top，检查空栈状态。
  - 提醒：本次新增；标准输入输出。动画中的入栈与出栈只是帮助观察，仍需自己分析怎样达到题目要求的最短结果。
- [ ] **进阶** · **新增补充** · [Codeforces 1066C · Books Queries](https://codeforces.com/problemset/problem/1066/C)
  - 训练重点：把书的稳定身份、记录位置与当前两端边界分开，处理双端插入和位置询问。
  - 关注指针：`front/back/pos`。
  - 移动观察：固定观察一本书，比较两端加入新书后它到 front/back 的距离；询问本身不应移动边界。
  - 提醒：本次新增；标准输入输出。题面说明询问不会真的移除书，不应把每次查询当作出队操作。
- [ ] **进阶** · **新增补充** · [Codeforces 797C · Minimal string](https://codeforces.com/problemset/problem/797/C)
  - 训练重点：区分输入扫描、临时栈与输出追加三个位置，并在合法移动之外考虑字典序要求。
  - 关注指针：`i/top/pos`。
  - 移动观察：逐步对比输入游标 i、临时栈 top 和输出写入位置 pos，观察字符在三个区域之间的移动。
  - 提醒：本次新增；标准输入输出。综合题需要字典序选择；读取输入串时可用下标推进，避免反复删除首字符造成大量搬移。
- [ ] **困难 · 选做** · **原题复练** · [Codeforces 1154E · Two Teams](https://codeforces.com/problemset/problem/1154/E)
  - 训练重点：观察从动态队列中取走一段学生后，剩余节点的左右邻居关系如何变化。
  - 关注指针：`current/prev/next`。
  - 移动观察：固定节点身份，比较一次选人前后 prev/next 所指的仍在队列中的邻居，不把原数组相邻位置当成当前邻居。
  - 提醒：原题单已收录；本次侧重双向链接的删除复练。困难选做，另需高效定位当前最大能力值；平台不要求唯一的数据结构。
