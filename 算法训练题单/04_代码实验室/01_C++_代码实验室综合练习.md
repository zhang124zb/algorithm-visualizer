## C++ 代码实验室综合练习

训练范围：把输入、状态、容器与输出连成完整单文件程序。

配套学习：[网站演示或教学页](https://zhang124zb.github.io/algorithm-visualizer/extensions/code-lab/index.html)。

选题说明：这是综合练习入口，不是新的算法门类。OJ 接受完整 C++17，浏览器实验室是教学子集；使用当前支持的语法改写，小数据执行动画，完整规模到 OJ 或本机 Docker 模式运行。不能保证任意官方题解代码直接在浏览器解释器执行。

- [ ] **模板** · [洛谷 P1001 · A+B Problem](https://www.luogu.com.cn/problem/P1001)
  - 训练重点：确认完整程序、标准输入与标准输出流程。
- [ ] **基础** · [洛谷 P1089 · \[NOIP 2004 提高组\] 津津的储蓄计划](https://www.luogu.com.cn/problem/P1089)
  - 训练重点：把循环、提前返回与逐月状态记录对应起来。
- [ ] **基础** · [Codeforces 4C · Registration System](https://codeforces.com/problemset/problem/4/C)
  - 训练重点：用字符串键映射维护状态并观察容器变化。
- [ ] **进阶** · [CSES 1646 · Static Range Sum Queries](https://cses.fi/problemset/task/1646/)
  - 训练重点：将输入数组、前缀数组与查询同步展示。
- [ ] **进阶** · [CSES 1667 · Message Route](https://cses.fi/problemset/task/1667/)
  - 训练重点：观察队列、访问标记与路径前驱的变化。
- [ ] **困难 · 选做** · [CSES 1675 · Road Reparation](https://cses.fi/problemset/task/1675/)
  - 训练重点：组合边排序、并查集与生成树计数。
  - 提醒：标准数据应在完整 C++17 环境提交；浏览器中用小数据复现状态。
